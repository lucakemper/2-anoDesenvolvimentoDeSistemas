**atividade 1:Pesquise sobre o que é um navegador, como funciona e quais são os principais atualmente**



**O que é um navegador: é um programa que permite acessar conteúdos da World Wide Web interpretando códigos HTML, CCSS e JavaScript.ele solicita arquivos de uma página ao servidor , processa cada elemento e exibe o resultado como textos,imagens, botões funcionais e vídeos tudo isso de maneira interativa.**



**como funciona:O processo começa quando o usuário digita uma URL ou toca em um link. O navegador aciona o DNS, serviço que converte o nome do site em um endereço IP. Com isso resolvido, envia uma solicitação HTTP ou HTTPS ao servidor responsável.**



**Depois de receber a resposta, composta por arquivos HTML, folhas de estilo e scripts, o motor de renderização monta a estrutura da página. O HTML cria o esqueleto do conteúdo, o CSS define aparência e layout, e o JavaScript adiciona interatividade.**



**O pipeline então é repetido constantemente enquanto o usuário navega, assegurando que os elementos apareçam, mudem e respondam aos comandos.**
